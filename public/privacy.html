Suss — Privacy Policy

Last updated: June 2026

Suss does not collect any personal information.

Data we do NOT collect

  • Names, email addresses, or contact information
  • IP addresses or device identifiers
  • Location data
  • Usage analytics or behavioral data
  • Cookies or tracking pixels

How the application works

  • When you create or join a game room, you provide a display name. This name exists only in temporary server memory for the duration of the game session. It is never written to a database, never logged, and is permanently discarded when the session ends.
  • Game state (room settings, roles, votes, scores) exists only in temporary server memory and is discarded when the room closes.
  • The offline pass-and-play mode runs entirely in your browser. No data leaves your device.

Third-party services

  • This application is hosted on Cloudflare Pages. Cloudflare may process standard web request metadata (IP address, user agent) as part of serving the application. This processing is governed by Cloudflare's own privacy policy (https://www.cloudflare.com/privacypolicy/). The developer does not access or store this data.
  • The multiplayer server runs on Partykit. Connection metadata may be processed by Partykit's infrastructure. The developer does not access or store this data.

Children's privacy

  • This application is not directed at children under 13. We do not knowingly collect any information from children under 13.

Changes to this policy

  • Any changes to this privacy policy will be reflected on this page with an updated date.
